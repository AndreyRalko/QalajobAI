ПАСПОРТ КЕЙСА ИИ-проекта
ОРГАНИЗАЦИЯ: НАО "Кокшетауский университет имени Шокана Уалиханова"
НАЗВАНИЕ КЕЙСА: Репозиторий редких книг с AI аналитикой
ОПИСАНИЕ ПРОБЛЕМЫ / ЗАДАЧИ: В рамках ежегодного обновления библиотечного фонда университет сталкивается с проблемой принятия решений о закупке новых изданий.
Задачи проекта:
определить, какие именно книги и издания необходимо закупать на основе реальных данных;
выявлять наиболее востребованные направления науки и обучения;
анализировать поисковые запросы пользователей;
определять дефицит литературы по конкретным тематикам;
формировать обоснованные рекомендации для ежегодного обновления библиотечного фонда;
снизить долю неэффективных закупок.
ПРОЦЕССЫ / ФУНКЦИИ ДЛЯ ВНЕДРЕНИЯ ИИ: Проект представляет собой цифровую платформу с внедрением технологий искусственного интеллекта.
AI-аналитика использования репозитория
Ключевым компонентом системы является модуль интеллектуальной аналитики, который анализирует поведение пользователей и формирует рекомендации по закупке литературы.
Функциональные возможности AI-аналитики:
1. Анализ поисковых запросов
сбор всех поисковых запросов пользователей;
нормализация (учет регистра, языка, синонимов);
кластеризация запросов по темам;
выявление часто повторяющихся запросов.
2. Выявление дефицита литературы
определение запросов, по которым отсутствуют или недостаточны материалы;
анализ «пустых поисков»;
выявление тем с высоким спросом и низким покрытием.
ОЖИДАЕМЫЙ ЭКОНОМИЧЕСКИЙ ЭФФЕКТ (в том числе % от закладываемого бюджета), ПОКАЗАТЕЛИ ДЛЯ ОЦЕНКИ ЭФФЕКТИВНОСТИ (KPI):
Экономический эффект:
Оптимизация закупа литературы
Закупаются только востребованные издания;
Исключаются нерелевантные покупки.
Снижение неэффективных расходов
Сокращение затрат на невостребованные книги до 10–15%.
Повышение эффективности бюджета
Перераспределение средств на приоритетные направления.
Обоснование закупа
Возможность предоставления аналитических отчетов для проверяющих органов и руководства.
КАК ЭТО БУДЕТ РАБОТАТЬ (ОПИСАНИЕ РЕШЕНИЯ):
6.1. Сбор данных
Система автоматически фиксирует:
поисковые запросы пользователей;
просмотры книг;
поведение пользователей в системе.
6.2. Обработка данных AI
очистка и нормализация запросов;
кластеризация по темам;
анализ частоты и динамики;
выявление дефицитов.
6.3. Формирование аналитики
AI-система:
определяет наиболее востребованные темы;
выявляет нехватку литературы;
формирует список рекомендаций.
6.4. Формирование отчетов
Администрация получает:
аналитические дашборды;
списки рекомендуемых закупок;
обоснование решений.
НЕОБХОДИМЫЕ ДАННЫЕ:
поисковые запросы пользователей;
данные просмотров книг;
метаданные книг;
статистика использования системы;

ПАСПОРТ КЕЙСА ИИ-проекта
ОРГАНИЗАЦИЯ: НАО «Кокшетауский университет имени Шокана Уалиханова»
НАЗВАНИЕ КЕЙСА: UniStats — система сбора, мониторинга и AI-аналитики показателей университета
ОПИСАНИЕ ПРОБЛЕМЫ / ЗАДАЧИ:
В университете отсутствует единая цифровая система для:
централизованного сбора показателей деятельности;
контроля сроков ввода данных;
автоматической интеграции с внешними источниками (LMS, HR, Scopus и др.);
аналитики и прогнозирования на основе данных.
Текущий процесс характеризуется:
ручным вводом данных и высокой вероятностью ошибок;
отсутствием прозрачности и контроля актуальности данных;
невозможностью оперативного анализа динамики показателей;
слабой связью между данными и управленческими решениями.
Цель проекта
Создание интеллектуальной системы, которая:
автоматизирует сбор и хранение показателей;
контролирует сроки и корректность ввода данных;
интегрируется с внутренними и внешними системами;
использует AI для анализа, прогнозирования и рекомендаций;
обеспечивает руководство инструментами принятия решений.
ПРОЦЕССЫ / ФУНКЦИИ ДЛЯ ВНЕДРЕНИЯ ИИ:
1. Интеллектуальный анализ показателей
анализ динамики показателей (рост / падение / аномалии);
выявление отклонений от нормы;
автоматическое определение проблемных зон.
2. Выявление аномалий (AI anomaly detection)
обнаружение резких скачков значений;
выявление ошибок ввода данных;
уведомление ответственных сотрудников.
3. AI-прогнозирование
прогноз значений показателей на будущие периоды;
анализ сезонности (например, учебные циклы);
сценарное моделирование.
4. Генерация текстовых AI-выводов
автоматическое формирование аналитических комментариев:
“Показатель снизился на 15% по сравнению с прошлым периодом”
“Наблюдается стабильный рост”
генерация отчетов для руководства.
ОЖИДАЕМЫЙ ЭКОНОМИЧЕСКИЙ ЭФФЕКТ (в том числе % от закладываемого бюджета), ПОКАЗАТЕЛИ ДЛЯ ОЦЕНКИ ЭФФЕКТИВНОСТИ (KPI):
Экономический эффект
Снижение трудозатрат
автоматизация сбора и обработки данных;
снижение ручной работы до 60–70%.
Повышение точности данных
уменьшение ошибок ввода;
автоматическая валидация данных.
Ускорение принятия решений
доступ к актуальной аналитике в реальном времени;
сокращение времени подготовки отчетов.
Повышение эффективности управления
переход к управлению на основе данных (data-driven);
выявление проблем до их критического уровня.
KPI
снижение ошибок ввода данных: –50%
доля автоматизированных показателей: ≥60%
сокращение времени подготовки отчетов: –70%
точность AI-прогнозов: ≥75%
уровень использования системы: ≥80% подразделений
КАК ЭТО БУДЕТ РАБОТАТЬ (ОПИСАНИЕ РЕШЕНИЯ):
6.1. Ввод данных
сотрудники вводят данные через веб-интерфейс;
система контролирует сроки (окна ввода);
возможен автоматический импорт данных.
6.2. Хранение и обработка
данные сохраняются в централизованной базе;
система хранит историю изменений.
6.3. AI-анализ
система анализирует:
динамику показателей;
отклонения;
взаимосвязи;
формирует аналитические выводы.
6.4. Визуализация
данные отображаются в виде:
графиков;
таблиц;
дашбордов.
НЕОБХОДИМЫЕ ДАННЫЕ:
показатели подразделений;
данные LMS;
кадровые данные;
научные показатели;
исторические данные;
внешние источники (API).
